# SacHacksVIII: HackRx Website

A medical-themed web app built for **HackRx**, the healthcare-focused hackathon track. It combines a clean, clinical UI with a demo dataset so judges can explore the product without any backend setup — everything runs client-side out of the box, with clear hooks for wiring in a real API later.

## Challenge Problem

Design and develop innovative technologies, platforms, or workflows that advance healthcare, accelerate translational medicine, and enhance the efficiency, accessibility, or impact of biomedical research.

## Tech stack

- Vite + React 18 + TypeScript
- Tailwind CSS v3 + shadcn/ui
- React Router v6
- Framer Motion (page transitions, subtle motion)

## Getting started

After cloning, run locally using:

```sh
npm install
npm run dev
```
